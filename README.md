# didactic-winner-MUKHTAR

مشروع Android مبدئي (Kotlin + Jetpack Compose)

ما سأفعله في هذا الفرع:
- إضافة هيكل مشروع Android (ملفات Gradle، تطبيق بسيط بـ Jetpack Compose).
- لن أحذف أو أغيّر أي ملف موجود حالياً (بما في ذلك copilot-deploy_credentials.csv) كما طُلِب.

كيفية البناء محلياً:
1. افتح المشروع في Android Studio (Arctic Fox أو أحدث).
2. سيقوم Gradle بمزامنة وتحميل الاعتمادات.
3. شغّل التطبيق على محاكي أو جهاز حقيقي.

إذا رغبت، بعد الدمج سأكمل:
- إعداد Hilt للـ DI
- إعداد Room لتخزين محلي
- مثال على استدعاء شبكة (Retrofit)
- تهيئة GitHub Actions لبناء CI
